# r-lsp

R language server for Claude Code, providing diagnostics, go-to-definition, hover, references, and formatting via languageserver.

## Supported File Extensions

- `.R`, `.r` — R scripts
- `.Rmd`, `.rmd` — R Markdown
- `.qmd` — Quarto documents

## Prerequisites

Install the R languageserver package:

```r
install.packages("languageserver")
```
